# Shree Ganesh Mitra Mandal – Frontend

Mobile-first PWA for mandal operations. Talks to the FastAPI backend.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173 on your phone (same Wi-Fi) using your PC IP, or use Chrome “Add to Home Screen”.

Demo login: `9999999999` / `admin123`

Start the backend on port 8000 first. Vite proxies `/api` to `http://127.0.0.1:8000`.
